How to Build a One-Person 24/7 AI Hedge Fund by Combining Opus 5.5, Jev, GPT-6 Astra & Muse Wonder

A field report on a five-role trading desk in which every frontier model does the one job it wins at, on shared data, compute, and execution infrastructure.

Abstract

Most AI trading systems fail in the same way. The builder picks one model and asks it to do everything, from research to execution, and the model fails at most of it. The strongest reasoner is too slow for a live market, the fastest model cannot reason, and none of them has ever seen a real price. Builders respond by waiting for a single model that does everything well, and that model has not arrived. Between September 3 and October 12, 2026, four frontier systems arrived that each lead a different capability. GPT-6 Astra leads frontier mathematics. Claude Opus 5.5 leads agentic coding with one million tokens of context. Jev returns calibrated decisions in seventy to five hundred milliseconds. Muse Wonder, released by Meta on October 12, leads long-horizon memory. We document a production desk that assigns each model the single role it is strongest at and connects all of them to one infrastructure layer, QuantGPT, which supplies decades of survivorship-aware data, cloud backtests that end in a held-out verdict, and hosted execution at the operator's own broker. Custom validation tooling is built with the AgentKit structured engineering harness, and a deterministic Rust engine owns every order and every risk veto. The central claim is that the most powerful AI trading system is not the best model. It is the best division of labour between models, on infrastructure that every one of them can share.

I. Introduction: the single-model trap

Every builder eventually asks which model is best for trading, and the question is wrong. A trading desk is not one job. It is research, mathematics, engineering, memory, and execution, and each job has a different binding constraint: depth, rigour, correctness, recall, and speed. A model chosen for depth is too slow for execution, and a model chosen for speed is too shallow for research. Whichever model is chosen, the desk inherits its weakest skill as its ceiling.

The correct response is not to search for one model that does everything. It is to separate the jobs and give each one to the strongest specialist available, then let all of them work from the same data and the same rules. This paper documents a desk built on that separation, with four frontier models in four seats, a Rust engine in the fifth, and Outt and QuantGPT as the shared trading floor beneath all of them. When a stronger model appears, it replaces one seat without rebuilding the desk.

The separation also changes how the desk fails. In a single-model system, one weak skill corrupts every decision downstream of it. In the five-role desk, a failure stays inside its seat, is caught by the next seat or by the Rust engine, and is written to the ledger so the same mistake is never made twice.

A. Why one model cannot run a desk

An operator who asks a single model to trade receives a confident answer with no data source, no test, and no record. A reasoner that spends twenty seconds per answer cannot sit inside a market that moves every block. A millisecond decision model cannot write the strategy it executes. A coding model with no memory repeats last week's failed experiment as if it were new. None of them can check its own work against decades of clean history. Each model was capable. The desk around it did not exist.

B. The five-role desk definition

This paper defines the desk as five roles on one infrastructure layer. Muse Wonder orchestrates each cycle, delegates the work, and remembers every finding, including every failure. GPT-6 Astra designs hypotheses and sizing rules precise enough to encode without interpretation. Opus 5.5 writes the code, runs the backtests, and reviews every session overnight. Jev makes the live judgment on every market state. A Rust engine holds the final risk veto. No model moves capital without operator approval.
